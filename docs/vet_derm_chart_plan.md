# 수의 피부과 차트 시스템 기획서

> Claude AI 연동 기준 문서 | 작성일: 2026-06-14

---

## 1. 개요

개/고양이 피부과 차팅의 진입장벽을 낮추고, 임상 데이터를 표준화하여 축적하는 웹 기반 피부과 차트 시스템.

**핵심 목표**
- 수의사의 차팅 부담 최소화
- AI가 구조화 및 용어 변환 담당
- 표준화된 데이터 축적 → 장기적으로 피부과 특화 AI 학습 데이터로 활용

---

## 2. 전체 워크플로우

```
전체사진 촬영
    ↓
병변 마킹 (포인트 / 영역)
    ↓
같은 종류 병변 그룹핑
    ↓
세부사진 드롭
    ↓
AI 분석 (Claude)
    ↓
모식도 자동 마킹
    ↓
심각도 분류 + 진료 조언
```

---

## 3. 단계별 상세 설명

### 3-1. 전체 사진 촬영

- 신체 부위가 식별 가능한 거리에서 촬영
- 해부학적 위치 파악용 기준 사진으로 활용
- 이후 재진 시에는 생략 가능

### 3-2. 세부 사진 촬영

병변 가시성을 높이기 위한 표준 촬영 프로토콜 권장

1. 털 가르기
2. 알코올 또는 물로 적시기 (병변 선명도 향상)
3. 크기 기준(자, 동전 등) 함께 촬영
4. 클로즈업 촬영

> 앱에서 단계별 촬영 가이드를 제공하면 데이터 품질 표준화 가능

**털 적시기 효과 비교**

| 방법 | 병변 가시성 | AI 인식 향상 |
|------|------------|-------------|
| 그냥 촬영 | 기준 | 기준 |
| 털 가르기 | ↑↑ | 꽤 향상 |
| 물 적시기 | ↑↑↑ | 많이 향상 |
| 알코올 적시기 | ↑↑↑↑ | 가장 좋음 |
| 털 가르기 + 알코올 | ↑↑↑↑↑ | 최상 |

### 3-3. 전체 사진 업로드 및 마킹

두 가지 마커로 병변 표시

- **포인트 마커** → 구진, 농포 등 단일 병변
- **영역 마커 (드래그)** → 홍반, 탈모 등 광범위 병변
- 마커에 번호 자동 부여 (①②③...)

### 3-4. 병변 그룹핑

같은 종류 병변끼리 색상으로 묶고 그룹 카드 자동 생성

```
[그룹 A 🔴] - 농포 의심
 마커 ① ②
 [세부사진 드롭존]

[그룹 B 🔵] - 홍반 의심
 마커 ③ ④ ⑤
 [세부사진 드롭존]
```

### 3-5. 세부 사진 드롭

- 해당 그룹 카드에 세부 사진 드래그 앤 드롭
- 그룹당 여러 장 허용

### 3-6. AI 분석 (Claude)

**Claude에게 전달하는 정보**
- 전체 사진
- 세부 사진들
- 마커 위치 및 그룹 구성
- 환자 정보 (종, 품종, 나이, 성별, 체중)
- 주증상

**Claude 출력 예시**
```json
{
  "group_A": {
    "anatomical_location": "좌측 액와부",
    "lesion_type": ["pustule"],
    "description": "다발성 농포, 중앙 농성 내용물",
    "confidence": 0.82,
    "severity": 2
  }
}
```

**병변 종류 미입력 시**

수의사가 병변 종류를 따로 입력하지 않아도 AI가 사진을 보고 추측하여 제안

```
[농포 (Pustule)]  82% → ✓ 승인 / ✎ 수정
[구진 (Papule)]   60% → 수의사 확인 필요 ⚠️
```

신뢰도가 낮은 항목은 반드시 수의사 확인 유도

### 3-7. 구어체 소견 → 정식 용어 변환

수의사가 편한 말로 소견을 입력하면 AI가 정확한 피부과 용어로 변환

**예시 1**
```
입력:  "겨드랑이에 가운데 농이 진 동그란 병변이 여러개 보여"
출력:  "액와부 다발성 농포. 원형, 중앙 농성 내용물 함유,
       직경 약 2-4mm 추정"
```

**예시 2**
```
입력:  "꼬추가루 뿌려놓은 것처럼 빨개"
출력:  "산재성 점상 홍반. 선홍색 다발성 소점상 병변,
       점출혈과 감별 필요"
```

- 음성 입력(STT) 연동 가능 → 촬영하면서 바로 소견 말하기
- 사진과 소견이 불일치하면 AI가 알림

### 3-8. 피부 모식도 자동 마킹

- AI가 전체 사진의 해부학적 위치를 파악하여 표준 모식도에 자동 표시
- 종별 대표 모식도 제공

**모식도 뷰 구성**
- Dorsal (등면)
- Ventral (배면)
- Left / Right lateral (좌우 측면)
- Head 클로즈업
- Paw 클로즈업

### 3-9. 심각도 분류

병변 종류 + 범위 + 개수 조합으로 AI가 자동 산정

| 등급 | 표시 | 기준 |
|------|------|------|
| Grade 1 | 🟢 | 경미, 단일 병변 |
| Grade 2 | 🟡 | 중등도, 다발성 |
| Grade 3 | 🟠 | 중증, 광범위 |
| Grade 4 | 🔴 | 매우 중증, 전신성 |

### 3-10. 진료 조언

```
[감별진단]
- 표재성 농피증 (가능성 높음)
- 아토피성 피부염 동반
- 말라세지아 감염 감별 필요

[추천 검사]
- 테이프 스트립 세포검사
- 피부 소파 검사

[즉각 조치]
- 2차 감염 범위 확인
- 항소양제 고려
```

## 4. 재진 시스템

- 초진 차트의 병변 그룹이 기준점으로 유지됨
- 재진 시 전체 사진 생략, 세부 사진만 해당 그룹에 추가
- AI가 초진 세부사진과 자동 비교 → 호전 여부 판단

**호전도 척도**

| 표시 | 판정 |
|------|------|
| 🔴 | 악화 |
| 🟠 | 변화없음 |
| 🟡 | 경미한 호전 |
| 🟢 | 호전 |
| ✅ | 완치 |

**시간축 추이 시각화**
```
병변 A (농포/액와부)
초진 🔴 → 2주 🟡 → 4주 🟢 → 6주 ✅
```

**처방 연동 시**
- 어떤 처치가 효과 있었는지 케이스가 쌓이면 패턴 파악 가능
- 비슷한 병변에 처방 참고 데이터로 활용

## 5. 병변 위치 표준화 (향후 과제 - 아이디어 단계)

### 기본 개념

사용자는 표준 모식도에 직관적으로 점만 찍고, 내부적으로 표준 좌표로 자동 변환 (사용자에게는 숨김)

```
사용자: 모식도에 점 찍기 (직관적)
            ↕ 내부 변환
시스템: 표준 좌표로 저장 (객관적)
```

### 좌표 체계 아이디어

**기준선**
- 코끝 ~ 꼬리끝 척추축 (전후 기준, 0~100%)
- 좌전지끝 ~ 우전지끝 횡단선
- 좌후지끝 ~ 우후지끝 횡단선

**랜드마크 앵커 (숨김 레이어)**
```
LM01 = 코끝          LM02 = 후두부
LM03 = 견갑골 전연   LM04 = 견갑골 후연
LM05 = 최후늑골      LM06 = 장골익
LM07 = 좌골결절      LM08 = 꼬리기부
LM10/11 = 견관절 좌/우
LM12/13 = 주관절 좌/우
LM18/19 = 고관절 좌/우
LM20/21 = 슬관절 좌/우
```

**저장 데이터 예시**
```json
{
  "segment": "LM03-LM10",
  "ratio": 0.15,
  "dorsoventral": 270,
  "region_label": "좌측 겨드랑이"
}
```

### 장기 목표

- 좌표 데이터 축적 후 역으로 부위 경계 정의
- "아토피 호발 부위는 좌표 X~Y 구간" 등 임상 패턴 도출
- 새 환자 마킹 시 "이 위치는 아토피 호발 부위입니다" 자동 안내

## 6. 데이터 축적 및 AI 학습 가치

표준화된 데이터가 쌓이면 단계적으로 활용 가능

| 단계 | 케이스 수 | 활용 |
|------|----------|------|
| 단기 | 수백 건 | 병변 인식 정확도 향상, 품종별 패턴 파악 |
| 중기 | 수천 건 | 감별진단 자동 제시, 유사 케이스 검색 |
| 장기 | 수만 건 | 수의 피부과 특화 AI 모델 학습 데이터 |

**데이터 품질 관리 원칙**
- 세포검사/조직검사로 확진된 케이스에 태그
- 불확실한 케이스는 별도 분류
- 보호자 데이터 활용 동의 및 익명화 필수
